# 声音后期制作工作室

Python 负责工程管理与声音处理，React（Vite + TypeScript）提供多轨编辑界面。
当前已完成：多轨素材放置、裁切、独听、静音、混音导出；素材内分段音量/声像
自动化（随片段移动）、轨道级音量/声像/效果强度自动化（绝对工程时间）、
轨道效果器链（增益、延迟/回声）、分块区间导出。

## 处理顺序（轨道 → 输出）

```
源文件（原始采样率，永不修改）
  → 重采样到工程采样率 + 声道统一
  → 素材裁切（in/out，非破坏）
  → 素材增益 + 素材内自动化（时间相对素材，随片段一起移动）
  → 轨道缓冲
  → 轨道效果器链（增益/延迟，按顺序执行；强度 amount 可自动化）
  → 轨道推子增益 + 声像 + 轨道自动化（时间为工程绝对时间，不随片段移动）
  → 闪避控制轨检测（静音控制轨仍参与；触发/进入/保持/恢复从工程零点连续计算）
  → 背景音乐轨闪避增益 + 静音/独听裁决（有任一独听轨时只输出独听轨；
                   静音轨始终排除，静音/独听不改变导出长度与其他轨时间位置）
  → 母线叠加
  → 主控增益
  → 输出范围检测（|采样| > 1.0 即超范围，报告时间区间）
  → WAV 导出（分块写入、可指定起止时间、原子替换、可取消）
```

## 关键约束如何保证

- **拖动/裁切不改素材**：工程 JSON 只保存 `start / in_point / out_point / gain` 等引用参数，
  源文件复制进 `session/media/` 后保持原样；恢复裁切区间即可还原完整素材。
- **工程保存后声音一致**：保存接口原子写 `project.json`，重开后按相同参数渲染；
  有往返一致性测试（保存前/后混音逐采样 allclose）。
- **采样率统一**：素材进入引擎前用 scipy polyphase 滤波重采样到工程采样率（默认 44100Hz）。
- **随片段 vs 留在工程时间**：素材自动化点存在 `clip.automation`，时间相对素材起点，
  移动片段时跟着走；轨道自动化点存在 `track.automation`，使用工程绝对时间，
  片段移动不会改变它们，因此可在指定时刻改变整条轨道的音量/声像/效果处理强度。
- **重复导出不叠加**：渲染只读取工程快照与只读的素材缓存（引擎内部全部使用副本），
  因此多次导出结果逐采样一致，不会把上次的延迟/增益叠加进工程或素材。
- **分块导出**：导出接口可传 `start_time` / `end_time`，分块渲染拼接与整段渲染一致；
  WAV 按约 1 秒一块写入，取消时只清理 `.part` 临时文件。
- **整段/分块/区间含义统一**：区间渲染在效果器前自动“预卷”一个效果尾长
  （延迟/回声的衰减时间），使分段起点保留之前的效果状态；音量/声像自动化
  按工程绝对时间逐采样插值，区间边界处连续。把整段切成相邻区间分别渲染再拼接，
  与整段渲染逐采样一致（测试报告重叠区误差为 0）。
- **效果尾音**：导出接口可传 include_tail=true，在所选区间之后继续导出效果器
  自然衰减与闪避恢复尾音；渲染结果用 content_end_time（片段/区间本身结束）与
  tail_end_time（尾音衰减完的结束）明确区分两个终点。改变起止、反复取消重导、
  保存重开都不会累加旧效果或截断仍应存在的余音（有对应测试）。
- **闪避中途导出状态一致**：主持人轨标记为 control、背景音乐轨标记为 music
  后，A/B 两套阈值、压低量、进入/保持/恢复时间可切换比较。即使控制轨静音，
  其移动、裁切、音量与效果后电平仍参与检测；区间导出从工程零点连续计算控制
  包络再截取，因此讲话中途导出的起始音量与整段渲染同一位置一致。检测结果返回
  duck_ranges，最终仍报告母线峰值与超范围区间；active_ducking=none 保留原混音。
- **叠加超范围明确提示**：导出前预检，超范围返回 409 与超范围时间区间，默认阻止导出；
  界面“检测混音”可随时查看峰值与区间，用户也可显式勾选“超范围仍导出”。
- **取消导出不留成品**：导出先写 `.export-*.wav.part` 临时文件，取消或失败时删除，
  只有完整写完才原子替换为目标文件。

## 目录

- `backend/studio/model.py` — 工程/轨道/素材模型与静音独听裁决
- `backend/studio/audio.py` — 读取、重采样、声道适配、原子导出、波形包络
- `backend/studio/engine.py` — 混音引擎与超范围检测
- `backend/studio/store.py` — 会话与 `project.json` 持久化
- `backend/studio/server.py` — 标准库 HTTP API + 可取消导出任务 + 前端静态托管
- `frontend/src/` — React 轨道编辑器（拖拽移动、两端手柄裁切、M/S、增益、导出对话框）
- `tools/make_test_sounds.py` — 生成 3 段可辨认人工核对素材到 `samples/`
- `backend/tests/` — 时间位置、混音、静音/独听、非破坏裁切、采样率、溢出、取消、往返测试

## 运行

后端（需要 numpy / scipy / soundfile）：

```bash
python3 tools/make_test_sounds.py            # 生成核对素材 samples/
cd backend && python3 run_server.py --port 8000
```

前端开发（开发服务器把 `/api` 代理到 8000）：

```bash
cd frontend
npm install        # 需要可访问 npm 源
npm run dev
```

或 `npm run build` 后由后端直接托管构建产物，访问 `http://127.0.0.1:8000/`。

## 用人工声音核对

`samples/` 下三段素材特征互不相同：

- `voice-a-low.wav`：440Hz，摩斯 A（短-长）节奏，44100Hz
- `voice-b-high.wav`：880Hz 连续音，22050Hz（验证重采样统一）
- `voice-c-pulse.wav`：1760Hz 急促脉冲，44100Hz

建议摆放：A 在 0s、B 在 1s、C 在 2s。正常增益导出后，
0.5s 处主频应为 440Hz、1.5s 为 880Hz、3.5s 为 1760Hz；
把 C 推到 +12dB 与 B 叠加时，“检测混音”会报告 2s 之后的超范围区间并阻止导出。

闪避核对可使用 0.50s 处 40ms 短脉冲与 0.30s-1.40s 连续方波/语音形状控制轨：
短脉冲用于确认进入、保持和恢复；两个相邻或近距离控制片段用于确认停顿保持；
切换 A/B 可比较触发阈值与恢复时间，并检查 duck_ranges 与最终峰值。
